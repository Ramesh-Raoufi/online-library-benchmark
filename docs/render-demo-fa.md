# انتشار نسخهٔ نمایشی در Render Free

این تنظیمات برای دیدن و آزمایش سیستم با دادهٔ نمونه است. SQLite روی دیسک موقت Render قرار دارد و اطلاعات آن ممکن است هنگام ری‌استارت، توقف سرویس یا انتشار مجدد پاک شوند. از این نسخه برای نگهداری اطلاعات واقعی یا سنجش نهایی مونوگراف استفاده نکنید.

1. در داشبورد Render گزینهٔ **New → Blueprint** را انتخاب کنید.
2. مخزن `Ramesh-Raoufi/online-library-benchmark` و شاخهٔ `main` را انتخاب کنید. اگر لازم بود، اتصال GitHub را فقط برای همین مخزن مجاز کنید.
3. Render فایل `render.yaml` را می‌خواند. پلن سرویس باید **Free** باشد.
4. `ADMIN_EMAIL` را ایمیل ورود مدیر و `ADMIN_PASSWORD` را یک رمز جدید، مخصوص این دمو و حداقل ۱۰ کاراکتری قرار دهید. رمز را در GitHub، چت یا اسکرین‌شات وارد نکنید.
5. انتشار را آغاز کنید. پس از وضعیت **Live** لینک سرویس را باز کنید و با همان ایمیل و رمز وارد شوید.

نام مدیر، ۱۲ کتاب نمونه و نسخه‌های فیزیکی هنگام نخستین راه‌اندازی ساخته می‌شوند. اگر دیتابیس موجود باشد، حساب مدیر تغییر نمی‌کند. با تغییر رمز در متغیر محیطی، رمز یک حساب موجود عوض نمی‌شود؛ تغییر حساب موجود را از داخل سیستم انجام دهید. پس از پاک‌شدن دیسک موقت، دمو با تنظیمات فعلی دوباره ساخته می‌شود.

تنظیم آدرس سایت برای کنترل Origin از `RENDER_EXTERNAL_URL` و پورت از `PORT` خود Render گرفته می‌شود. اگر دامنهٔ اختصاصی اضافه کردید، `APP_ORIGIN` باید همان دامنه باشد و فرمان شروع نیز متناسب با آن تغییر کند.

اگر از **New → Web Service** استفاده می‌کنید، مخزن را انتخاب کنید، Runtime را Node، Branch را main، Root Directory را خالی، Build Command را `npm ci --ignore-scripts` و Start Command را `APP_ORIGIN="$RENDER_EXTERNAL_URL" npm run start:demo` قرار دهید. پلن Free را انتخاب و متغیرهای `render.yaml` را وارد کنید. `PORT` را دستی تنظیم نکنید.

منابع رسمی: https://render.com/docs/free و https://render.com/docs/infrastructure-as-code
